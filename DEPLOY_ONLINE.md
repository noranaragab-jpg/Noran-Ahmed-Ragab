# Publish the Basal Heave Calculator as a Web Link

## Files to upload to GitHub

Upload the full contents of this folder, preserving the `data` and `.streamlit` folders.

## Streamlit Community Cloud

1. Create a new GitHub repository, for example `basal-heave-calculator`.
2. Upload all files and folders in this package to the repository root.
3. Sign in to Streamlit Community Cloud using GitHub.
4. Select **Create app**.
5. Choose the repository and the `main` branch.
6. Set the main file path to `app.py`.
7. Select **Deploy**.
8. Copy the generated `streamlit.app` address and send it to the supervisor.

The supervisor only needs a browser. No Python or file download is required.
